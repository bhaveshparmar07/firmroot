# Firmware Security Findings

This directory contains AI-analyzed security findings from firmware images, processed by the Firmroot pipeline.

## Data Format

Each finding includes:
- `finding_id`: Unique identifier
- `title`: Short name for the finding
- `explanation`: Plain-language risk explanation
- `priority`: High / Medium / Low
- `attack_scenario`: How this would actually be exploited
- `permanent_fix`: The real engineering fix
- `immediate_mitigation`: What to do right now without a firmware update
- `compromise_indicators`: What to check for if already exploited

## Pipeline

These findings were generated by:
1. Firmware extraction (binwalk/unsquashfs/UBI)
2. Service enumeration (init scripts)
3. Binary symbol analysis (network/file-write/auth/privilege-drop buckets)
4. Gemini AI triage with structured schema

See `src/firmroot/` for the pipeline code.
